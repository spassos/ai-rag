# 07 — Glossário

> Termos de finanças públicas usados no corpus e nas respostas. O objetivo é
> tornar as respostas compreensíveis a leigos ([Constituição P7](00-constitution.md)).

| Termo | Significado |
| --- | --- |
| **Orçamento** | Lei que estima receitas e fixa despesas do governo para o ano. |
| **Dotação orçamentária** | Valor autorizado no orçamento para uma finalidade específica. |
| **Empenho** | Primeira etapa da despesa: o governo reserva o valor para um compromisso. |
| **Liquidação** | Segunda etapa: verifica-se que o bem/serviço foi entregue. |
| **Pagamento** | Terceira etapa: o valor é efetivamente pago ao fornecedor. |
| **Ação orçamentária** | Unidade do orçamento que agrupa despesas com um mesmo objetivo. |
| **Órgão / Unidade Gestora** | Estrutura do governo responsável por executar despesas. |
| **Licitação** | Processo para contratar fornecedores de forma competitiva. |
| **Modalidade de licitação** | Tipo de certame (pregão, concorrência, etc.). |
| **Dispensa de licitação** | Contratação direta permitida por lei em casos específicos. |
| **Inexigibilidade** | Contratação direta quando a competição é inviável (fornecedor único). |
| **Contrato** | Acordo formal entre órgão e fornecedor com objeto, valor e vigência. |
| **Aditivo (termo aditivo)** | Alteração de um contrato (valor, prazo, objeto). |
| **Convênio** | Repasse de recursos a entes/entidades para um objetivo comum. |
| **Convenente** | Parte que recebe os recursos de um convênio. |
| **Emenda parlamentar** | Recurso direcionado por parlamentar a uma destinação específica. |
| **Fornecedor / Credor** | Pessoa jurídica ou física que recebe pagamento do governo. |
| **CNPJ** | Cadastro Nacional da Pessoa Jurídica; identificador único de empresas. |
| **CPGF / Cartão de pagamento** | Cartão corporativo do governo para certas despesas. |
| **Controle social** | Acompanhamento dos gastos públicos pela própria sociedade. |

## Termos técnicos do sistema

| Termo | Significado |
| --- | --- |
| **RAG** | Retrieval-Augmented Generation: o LLM responde com base em documentos recuperados. |
| **LightRAG** | Motor de RAG que combina knowledge graph e busca vetorial dual-level. |
| **Knowledge graph** | Grafo de entidades e relações (ver [05](05-knowledge-graph.md)). |
| **Embedding** | Representação numérica de texto usada para busca por similaridade. |
| **pgvector** | Extensão do PostgreSQL para armazenar e buscar embeddings. |
| **Ponto de atenção** | Padrão atípico sinalizado para investigação — **não** é acusação ([P4](00-constitution.md)). |
